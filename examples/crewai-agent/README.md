# CrewAI agent example

A CrewAI `Task` that uses the `@astroid/client.budgets.consume` tool to check
budget headroom before delegating spend.

Shows how the [PRD's Policy-Aware Reasoning](../../ASTROID_PRD.md#document-6--ai-system-architecture)
flow maps to tool use.

> The PRD ships TypeScript. A Python port is planned for Phase 2 — see the
> [SDK roadmap](../../ASTROID_PRD.md#document-8--sdk-architecture-astroid-sdk).
