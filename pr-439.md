# Implement Agent Lifecycle Resource Methods

Closes #439

## Summary

- Add typed `createAgent`, `listAgents`, and `updateAgent` methods to `AgentResource`, delegating to the existing validated CRUD methods so payload validation, pagination, and request options remain consistent.
- Add `suspendAgent`, implemented as the documented partial status update (`PATCH /agents/:id` with `{ status: 'SUSPENDED' }`). This reuses `UpdateAgentParams` validation and avoids assuming an undocumented suspension endpoint.
- Forward request body and options explicitly for `deactivate`, preserving the existing archive endpoint while fixing lifecycle request expectations.

## Tests

- Cover the named CRUD aliases and their request payloads/filters.
- Cover suspension success, API errors, encoded IDs, and request-option forwarding.
- Verify lifecycle deactivation requests include the expected body and options arguments.
